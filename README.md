A multi-device online **Tambola (Housie)** web application crafted with a **3D floating ball background**, **tactile paper cards & die-cut stickers**, **animated hand-drawn pen cross marks**, and a **3D folding paper winner reveal**.

---

## ✨ Key Features

- **🌐 Any Network • Any Area Play:** Multi-STUN & TURN ICE relay configuration + 1-click shareable invite links (`?room=TAM-XXXX`) with live player roster and auto-reconnect.
- **🎨 3D Paper & Sticker Aesthetics:**
  - Real-time 3D perspective canvas with floating numbered Tambola spheres.
  - Lined cream paper panels with corner washi tape, die-cut sticker buttons, and **Digital Swami** watermarks.
- **✒️ Pen-Written Cross Animation:** Tapping a called number animates two red ballpoint-pen strokes and a blue ink loop directly over the cell.
- **🏆 3D Folding Paper Winner Reveal:** Unfolds an origami-style wax-sealed paper card across all devices whenever a prize is claimed and verified.
- **📜 Built-In Rules & Anti-Bogey Verification:** Interactive rules booklet modal, multi-round reset (`🔁 New Round`), `localStorage` session recovery, and host-side validation for **Jaldi Five**, **Top Line**, **Middle Line**, **Bottom Line**, **Four Corners**, and **Full House**.

## 🚀 Quick Deploy on GitHub Pages

1. Push this repository to GitHub (`main` branch).
2. Navigate to **Settings → Pages → Build and deployment**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
4. Open your live `https://<username>.github.io/<repo-name>/` URL, host a room, and share the invite link!
